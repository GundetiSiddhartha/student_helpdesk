
# Student Helpdesk Ticket Management System

## Project Description
A simple Python project that allows students to create helpdesk tickets and track their issues.

## Features
1. Create Student Tickets
2. Enter Student ID
3. Select Ticket Category
4. Add Problem Description
5. Optional Attachment Name
6. View Tickets
7. Update Ticket Status

## Technologies Used
- Python
- Object-Oriented Programming
- Git
- GitHub

## How to Run

```bash
python student_helpdesk.py
```

## Ticket Status
- Open
- In Progress
- Resolved
